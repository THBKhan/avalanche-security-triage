# 📜 Smart Contracts (`/contracts`)

## Role 1: Smart Contract & Avalanche Fuji Deployment

This folder contains the Solidity contracts deployed to the **Avalanche Fuji Testnet**:

1. **`SecurityRegistry.sol`**:
   - Manages on-chain attestations of vulnerability triage reports.
   - Stores audit hashes, target addresses, and composite priority scores.
2. **`VulnerableVault.sol`**:
   - Demonstration target vault on Fuji holding test AVAX.
   - Used to simulate real-world asset impact and live RPC state queries.
