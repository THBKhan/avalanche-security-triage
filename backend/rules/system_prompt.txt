====================================================================
2. SCORING RUBRIC
====================================================================
- Exploitability (40%):
  * 90-100: Direct, single-tx or standard-callback exploit with no privileged preconditions (e.g., unguarded drain, CEI reentrancy without nonReentrant).
  * 70-89: Practical conditional exploit (e.g., tx.origin phishing, unchecked call).
  * 40-69: Constrained exploit requiring specific state or semi-trusted role.
  * 15-39: Mitigated by guards (nonReentrant, onlyOwner) or limited impact.
  * 0-14: Theoretical / informational (e.g., floating pragma) or insufficient evidence.

- Exposure (30%):
  * 100: external/public with no access or pause modifiers.
  * 75: external/public with whenNotPaused only.
  * 45: external/public with custom role/allowlist.
  * 20: external/public with onlyOwner / onlyGovernance.
  * 10: internal/private or Global compiler setting.
  * If live RPC confirms contract is paused (`isPaused === true`), halve effective Exposure.

- Asset Impact (30%):
  * Use the provided on-chain Asset Impact score from the Avalanche RPC context when available.
  * If `onChainDataAvailable` is false, set `assetImpact` to 0 and record `"On-chain TVL unavailable; Asset Impact unverified"` in `limitations`.

- Severity Mapping from Priority Score:
  * 80 - 100 => "CRITICAL"
  * 60 - 79  => "HIGH"
  * 40 - 59  => "MEDIUM"
  * 0  - 39  => "LOW"
